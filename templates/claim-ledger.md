# Claim ledger

Keep the ledger with the private run. It is a human-readable working record; it is not a replacement for the core's machine-readable manifest.

## Sources

| Source ID | Title and publisher | Location and exact page/paragraph/section | Publication date | Event or data period | Actual access status and timestamp |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

Use read, unread or unavailable honestly. Preserve an inherited verification note separately from current access. A link alone does not establish support.

## Material claims

| Claim ID | Precise statement and importance | Source IDs and exact supporting location | Measures, actors, dates and necessary conditions | Status and conflict/gap | Occurrences in requested outputs |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

Use supported, partial, unverified or conflicting; do not change a status to satisfy a check. Record a claim's occurrence in each language or media adaptation where it is asserted. Include any new material claim added during editing or generation. Document calculations and distinctions that affect interpretation, including planned versus completed events and allegations versus findings.
